# 1.1.0 更新宣传片分镜（1920×1080 · 30fps · 30s）

剪辑网格：每 300 ms 一个脉冲，所有切点都落在脉冲上。
  所配音乐实测自相关在 900 ms(66.7 BPM) 与 600 ms(100 BPM) 都强，
  重拍间隔 305 ms —— 三者都是 300 ms 的整数倍，所以切点量化到 300 ms
  后无论真实速度是哪个，剪辑都踩在拍上。
音乐：用 `promo\video\混入音乐.ps1 -Music <文件> -Offset <秒>` 混入。

| 时间 | 时长 | 画面 | 文案 |
|---|---|---|---|
| 00.0s | 4.8s | 应用图标 + 标题 |  |
| 04.8s | 6.6s | Windows 11 窗口横向擦除成 Windows 10 |  |
| 11.4s | 6.0s | 放大镜看真实窗口的模糊与噪点 |  |
| 17.4s | 7.2s | 光标划过窗口，柔光跟随（真实渐变） |  |
| 24.6s | 2.4s | 弱 / 标准 / 强 三档并排 |  |
| 27.0s | 3.0s | 图标 + 下载信息 |  |

## 实际配乐参数

| 项 | 值 |
|---|---|
| 音乐 | `M5000045HEAS14eII5.mp3`（4:29，128 kbps，44.1 kHz） |
| 起点 | 132.37 s（最响的 30 s 窗口 133.89 s 前的重拍） |
| 音量 | 0.40，响度归一到 -18 LUFS，结尾淡出 1.8 s |
| 切点 | 每 300 ms 一个脉冲，共 100 个 |

命令：

```bat
powershell -File promo\video\混入音乐.ps1 -Music "<音乐>" -Offset 132.37 -Volume 0.40 -FadeOut 1.8
```
